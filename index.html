Projects

H5 Games

Space Shooter

Is an arcade-style shooter where the player pilots a spacecraft and eliminates incoming enemies while avoiding collisions. The game features projectile mechanics, enemy spawning, and a scoring system that increases as the player survives longer and destroys enemies. The game was developed using JavaScript and HTML5 Canvas, implementing a real time game loop, object-oriented entity management, and collision detection between bullets, enemies, and the player. Enemy behavior and projectile movement were designed to create increasing difficulty over time. This project highlights my experience with real time rendering, game physics, and modular JavaScript architecture.

Mini Games

This project is a collection of small arcade style games built to experiment with different gameplay mechanics and programming patterns. Each mini game focuses on a specific concept such as player movement, obstacle avoidance, or timing-based interactions. The collection was built using JavaScript, HTML, and CSS, emphasizing reusable components and simple game loops. These games served as a sandbox for testing gameplay ideas and improving my understanding of browser-based game development. This project demonstrates my ability to rapidly prototype ideas and implement systems using JavaScript.

Road Bomber

Road Bomber is a fast paced endless runner where the player must avoid enemies and environmental hazards while traveling as far as possible. The game features dynamic obstacle spawning, scrolling terrain, and collectible coins that increase the player’s score. The project was built using HTML5 Canvas and JavaScript, with an object-oriented architecture separating entities such as the player, enemies, platforms, and collectibles. Collision detection, procedural obstacle generation, and responsive canvas resizing were implemented to create smooth gameplay across different screen sizes. This project demonstrates my experience with game loops, collision systems, and JavaScript design.
